# تحديث تصميم شريط أقسام الكاشير (v0.52.17)

## المشكلة
تبويبات الأقسام بدون صورة كانت تظهر كدائرة رمادية عادية بحرف واحد فقط — غير متّسقة
بصرياً مع تبويبات الأقسام اللي عندها صورة مرفوعة. كذلك، لو عدد الأقسام زاد عن عرض
الشاشة، كانت التبويبات تلتف لصف ثانٍ وتاكل من مساحة شبكة المنتجات بدل التمرير الأفقي.

## التغيير
- **شكل موحّد لكل الأقسام**: صورة لو موجودة، وإلا أيقونة حرف على خلفية متدرّجة اللون
  (لون ثابت مشتق من معرّف القسم)، بنفس حجم وشكل تبويبات الصور — بدل الدائرة الرمادية
  العادية. لو تعذّر تحميل صورة (ملف محذوف/مسار خاطئ) يرجع تلقائياً لنفس أيقونة الحرف.
- **شريط أفقي قابل للتمرير** (زي تبويبات المتصفح): عرض ثابت لكل تبويب، تمرير بعجلة
  الماوس، وزرّا سهم (◀ ▶) يظهران فقط عند وجود أقسام مخفية فعلاً خارج حدود الشاشة —
  يختفيان تلقائياً لو الأقسام تتسع للعرض بالكامل. يدعم الاتجاهين RTL وLTR والوضع الداكن.
- التبويب النشط يُمرَّر تلقائياً لمنتصف الشاشة عند الضغط عليه ولو كان بعيداً في شريط طويل.

## الملفات المعدّلة
- `renderer/index.html` — إضافة حاوية `categoryTabsWrap` مع زرّي التمرير.
- `renderer/pos.js` — إعادة كتابة `initCategoryTabs` (أيقونة ملوّنة بدل الحرف العادي،
  fallback عند فشل تحميل الصورة) + منطق تمرير الشريط (`initCategoryTabsScroll`,
  `updateCategoryScrollButtons`).
- `renderer/style.css` — تنسيق شريط الأقسام الجديد وزرّي التمرير.
- `tools/category-image-removal-regression.js` — تحديث الـ regex ليطابق العنصر
  الجديد (نفس الضمان الأصلي: القسم بلا صورة لازم يحتفظ بعنصر fallback بكلاس
  `category-tab-icon`)، دون تغيير جوهر الفحص.

- فحص `node --check` على كل ملفات JS (154 ملف): PASS.
- كل ملفات regression الموجودة (`full-regression.js` وتوابعه، `v0.12`, `v0.15`,
  `v0.43.0`, `freeze-regression.js`, `security-regression.js`,
  `category-image-removal-regression.js`): PASS.
- اختبار بصري بمتصفح headless (Chromium) على عدة سيناريوهات:
  - أقسام قليلة (بدون تمرير) — بصور، وبدون صور، ومختلطة.
  - أقسام كثيرة تتجاوز عرض الشاشة — تحقق التمرير فعلياً (يمين/يسار) وظهور/اختفاء
    الأزرار حسب الحاجة.
  - اتجاه RTL واتجاه LTR (تبديل اللغة للإنجليزية) — تأكيد انعكاس الاتجاه صح.
  - الوضع الداكن.
- تم اكتشاف وإصلاح خلل أثناء الاختبار: أيقونة السهم داخل زرّي التمرير كانت لا تظهر
  بصرياً بسبب تعارض `box-sizing: border-box` (المطبّق عالمياً بالمشروع) مع الحشو
  الداخلي لعنصر SVG — تم إصلاحها بتحديد `box-sizing: content-box` صراحة لهذا العنصر.
