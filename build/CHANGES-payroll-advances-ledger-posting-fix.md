# إصلاح: سلف الموظفين لم تكن تُرحَّل محاسبياً بدفتر اليومية

## الخلل
كل حركة نقد أخرى بالتطبيق (بيع، مرتجع، فاتورة شراء، تسديد دين عميل، دفعة لمورد،
صرف راتب عادي) ترحّل قيداً محاسبياً موازياً بدفتر اليومية (`accounting_journal_entries`)
بالإضافة لتسجيلها بحركة الصندوق (`cash_movements`). سلف الموظفين لم تكن كذلك:

- `createPayrollAdvance` (صرف سلفة) — يسجّل حركة صندوق فقط عند الصرف الفوري نقداً،
  بلا أي قيد محاسبي.
- `repayPayrollAdvance` / `settlePayrollAdvance` (تسديد سلفة مباشر) — نفس الشيء.

الأثر: رصيد حساب "النقد" (1000) و"البنك" (1100) بميزان المراجعة والمركز المالي لا
يطابق نقدية الصندوق الفعلية بمجرد استخدام هذه الميزات، لأن الصرف/التسديد يظهر
بحركة الصندوق لكنه غائب تماماً عن دفتر اليومية.

## الإصلاح (v0.52.15+)
- ترحيلة جديدة `payroll-advances-accounting-v22`: تضيف حساب أصل جديد **1400 — سلف
  موظفين** بكل فرع (لا تعدّل ترحيلة v3 المحاسبية المنشورة والمحسوبة بصمة).
- `createPayrollAdvance`: عند الصرف الفعلي (نقداً من الصندوق، أو bank/other التي
  تُعتبر دائماً مصروفة فوراً) يُرحَّل قيد: مدين 1400 / دائن حساب التسوية (1000 أو 1100).
  سلفة نقدية مسجّلة بلا صرف فوري لا تُرحَّل شيئاً (لم يخرج نقد بعد).
- `repayPayrollAdvance` (ويُستخدم أيضاً من `settlePayrollAdvance`): يُرحَّل قيد مقابل
  عند كل تسديد مباشر: مدين حساب التسوية (1000 أو 1100 حسب `method`) / دائن 1400
  (تخفيض الأصل) — نفس نمط `receiveCustomerPayment`/`paySupplierDebt` تماماً.

## معروف ولم يُعالَج بهذا الإصلاح
`settleEmployeeFinalPayroll` (التصفية النهائية عند إنهاء الخدمة) لديها نفس الفجوة:
مبلغ التصفية المدفوع فعلياً (نقد/بنك) لا يُرحَّل بدفتر اليومية إطلاقاً، ورصيد السلف
المُقاصّ ضمنها لا يُصفّى من حساب 1400. لم يُعالَج عمداً لأن صيغة حساب صافي التصفية
النهائية (`calculatePayrollFinalSettlement`) تخصم **كامل رصيد السلف المتبقي** دفعة
واحدة، بينما نموذج الاستحقاق الشهري العادي (`syncPayrollEmployeeAccrual` /
`recalcPayrollEmployeeMonth`) يخصم فقط **القسط المجدوَل لهذا الشهر** من صافي الراتب
المستحق (2300). التوفيق بين الرقمين لبناء قيد متوازن وصحيح محاسبياً يحتاج قراراً
تصميمياً واضحاً (هل تُعاد صياغة الاستحقاق الشهري ليفصل مصروف الراتب الكامل عن تسوية
السلفة بدل تصفية أعمى بينهما؟) بدل تصحيح آلي قد يُخفي المشكلة بقيد متوازن شكلياً لكنه
غير صحيح جوهرياً. يُنصح بمراجعة محاسب/مطوّر مختص قبل ترحيل أي قيد لهذه الحالة.
