# أيقونات التطبيق (مطلوبة قبل التحويل لـ exe)

ضع ملفات الأيقونة هنا بهذه الأسماء بالضبط (يقرأها `electron-builder` تلقائياً حسب `package.json`):

- `icon.ico` — لويندوز (يفضّل يحتوي أحجام 16/32/48/256 بكسل داخل نفس الملف)
- `icon.icns` — لماك
- `icon.png` — لينكس (1024×1024 بكسل يعطي أفضل نتيجة)

## كيف تجهزها من شعارك
1. صمّم الشعار بصيغة PNG مربّع بحجم 1024×1024 بكسل بخلفية شفافة.
2. حوّله للصيغ الثلاثة بأداة مجانية مثل:
   - https://icoconvert.com (لـ .ico و .icns)
   - أو أمر `electron-icon-builder` (يُنصف تلقائياً من صورة PNG واحدة):
     ```bash
     npm install --save-dev electron-icon-builder
     npx electron-icon-builder --input=./logo-1024.png --output=./build --flatten
     ```

بدون هذه الملفات، سيستخدم `electron-builder` أيقونة Electron الافتراضية عند التشغيل — التطبيق سيعمل بشكل طبيعي، لكن الأيقونة لن تكون شعارك الخاص.

> ملاحظة: هذا الشعار في الأيقونة (icon) منفصل عن "شعار المتجر" في شاشة الإعدادات — ذاك يظهر على الفاتورة المطبوعة فقط.
