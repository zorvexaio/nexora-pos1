# إعادة تصميم بطاقات المنتجات بشاشة الكاشير (v0.52.17)

## المشكلة
شاشة الكاشير (renderer/index.html + pos.js) كانت صعبة القراءة بسرعة:
- بطاقة المنتج: السعر (كبير أزرق) أبرز بصرياً من اسم المنتج (صغير أسود) — عكس
  الأولوية الفعلية اللي الكاشير محتاجها (يلقط الصنف بالاسم أولاً).
- ما في أي رمز/أيقونة تمثيلية للمنتج — التعرّف يعتمد بالكامل على قراءة النص.
- بطاقة "الحزمة/العرض" (bundle-card) كانت خلفية ذهبية كاملة مختلفة تماماً عن باقي
  البطاقات، فتُقرأ بصرياً كحالة تحذير/خطأ لا كخيار إضافي جذّاب.
- الشبكة (150px لكل بطاقة) بطاقات صغيرة نسبياً مقارنة بمساحة الشاشة المتاحة.

## التغيير
- **أيقونة رمزية لكل صنف**: دالة جديدة `guessItemIcon(name)` بـ pos.js تطابق كلمات
  شائعة بالاسم العربي (فروج/شاورما/مشاوي/مشروبات/بيتزا/برجر...) مع إيموجي مناسب،
  وإلا ترجع أول حرف. تُستخدم كخلفية ملوّنة (نفس تدرّج ألوان تبويبات الأقسام) أعلى كل
  بطاقة منتج، وأيضاً كـ fallback لتبويبات الأقسام بلا صورة (بدل حرف واحد بلا دلالة).
- **تسلسل بصري مقلوب لصالح الاسم**: اسم المنتج الآن أبرز عنصر نصي بالبطاقة، والسعر
  أصبح "شارة" (pill) هادئة بدل رقم أزرق ضخم ينافس الاسم.
- **بطاقة الحزمة أُعيد تصميمها**: نفس شكل بطاقة المنتج العادية (خلفية بيضاء) + شارة
  صغيرة "عرض" بالزاوية العلوية بدل خلفية ذهبية كاملة — تبقى مميزة بدون أن تبدو كخطأ.
- **شبكة أكبر**: `minmax(150px,1fr)` → `minmax(190px,1fr)`، فجوة 12px → 14px، حشو
  داخلي أكبر — استغلال أفضل للمساحة المتاحة وبطاقات أسهل باللمس.

## الملفات المعدّلة
- `renderer/pos.js` — `guessItemIcon()` جديدة، إعادة بناء `renderProducts()`
  (بطاقة منتج + بطاقة حزمة)، استخدام نفس الدالة كـ fallback بـ `initCategoryTabs`.
- `renderer/style.css` — إعادة تصميم `.product-card`/`.bundle-card` (أيقونة، شارة
  سعر، شارة عرض)، تكبير `.products-grid`.

## التحقق
- `node tools/full-regression.js`: PASS (155 ملف JS تم فحص صياغتها).
- `node tools/category-image-removal-regression.js`: PASS (fallback الأقسام
  لسا يحتفظ بعنصر `category-tab-icon` كما يتوقع الفحص).
- لم يُختبر بصرياً على جهاز حقيقي (بيئة العمل هنا بلا Electron/شاشة) — يُرجى
  فتح `npm start` والتأكد بصرياً قبل الاعتماد النهائي.
