# Nexora POS v0.50.0 — Payroll Advances

- Added scheduled employee advances with 1–36 repayment installments.
- Added explicit first deduction month.
- Added minor-unit based installment calculation with remainder on the final installment.
- Added optional immediate cash-out integration with the open register shift.
- Payroll recalculation now includes scheduled advance installments automatically.
- Added advances API, audit event, and employee drawer visibility.
- Added migration v12 and dedicated regression coverage.
