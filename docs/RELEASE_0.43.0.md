# Nexora POS 0.43.0 — Product UX Release

This release turns the current feature-complete base into a more coherent paid-product experience.

- Upgraded POS empty/loading/error states and resilient product search feedback.
- Improved cart hierarchy, item count, checkout guidance and keyboard-first operation.
- Added reusable success/error/info toasts and consistent visible feedback for settings operations.
- Strengthened reports loading/error status and invoice search resilience.
- Improved table screen empty/loading/error recovery.
- Added global focus-visible treatment, modal Escape handling and Ctrl/Cmd+Enter form submission.
- Fixed a duplicated barcode predicate return in the POS renderer.
- Preserved existing IPC, security and branch-boundary protections.
