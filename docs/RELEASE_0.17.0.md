# Nexora POS v0.17.0

## إصلاحات هذه الجولة

- إصلاح خطأ runtime في محرك تسعير البيع كان يستخدم متغير `quantity` غير معرّف بدل `item.quantity`.
- حماية تفاصيل جلسات الصندوق وحركاتها بحيث لا يستطيع الكاشير رؤية جلسة موظف آخر، بينما المدير والمدير العام يستطيعان الإدارة.
- جعل تعداد الفروع خلف صلاحية المدير العام/المسؤول بدل كشف قائمة الفروع لكل مستخدم مسجل.
- جعل تقارير اليوم/الأسبوع/الشهر تعتمد المنطقة الزمنية المحددة للمؤسسة، مع تحويل حدود اليوم المحلية إلى UTC قبل الاستعلام عن SQLite.
- تحديث شاشة التقارير لترسل تواريخ محلية واضحة بدل بناء نطاقات UTC في المتصفح.
- إضافة اختبار `tools/v0.17-regression.js` للسلوكيات الجديدة.

## ملاحظة

بناء Electron/SQLite native وتوقيع installers يحتاج بيئة بناء كاملة مع dependencies الأصلية؛ اختبارات المصدر وregressions يمكن تشغيلها بدون هذه الطبقة.
