# Nexora POS v0.14.0 — Input Freeze Hardening

## إصلاح مشكلة تجمد الإدخال

- تحديد نتائج بحث المنتجات والعملاء لمنع استهلاك الواجهة عند الكتالوجات الكبيرة.
- أحدث طلب بحث فقط يحق له تحديث الواجهة، لمنع سباق الاستجابات.
- منع تنفيذ أكثر من عملية قراءة باركود في الوقت نفسه.
- تأجيل حفظ مسودة السلة بدل الكتابة المتزامنة إلى localStorage مع كل حرف.
- تحويل حقول الدفع المتكررة إلى text + inputmode مع دعم الأرقام العربية/الفارسية.
- إعادة استخدام AudioContext بدل إنشائه عند كل إنذار باركود.
- إضافة تشخيص آمن لتجمّد renderer مع rate-limit داخل سجل التدقيق.
- إضافة فهارس branch-scoped للاستعلامات المتكررة.
- إصلاح خطأ مضاعفة وزن باركود الميزان.

## ملاحظة

لا يتم إعادة تحميل الصفحة تلقائيًا عند اكتشاف stall؛ الهدف هو منع فقدان السلة والبيانات، مع تسجيل الحدث للتحقيق.
