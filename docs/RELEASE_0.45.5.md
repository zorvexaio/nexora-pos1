# Nexora POS v0.45.5 — Payroll Workspace

- Replaced the old payroll-cycle UI with a single monthly payroll workspace.
- Users select a month instead of opening/closing payroll cycles.
- Added monthly payroll KPIs, employee payroll table, direct employee actions, and payout workflow.
- Payroll periods remain an internal accounting record; the UI creates/reuses the month's record automatically.
- Added consolidated employee salary settings and payroll history.
- Preserved approval/payment safeguards for already-paid payroll.
