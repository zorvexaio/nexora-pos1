# Nexora POS 0.6.0

## Production Hardening

هذه النسخة مبنية فوق v0.5.1 مع تدقيق إضافي للبيانات والصلاحيات والاستعادة والمزامنة.

### تم إصلاحه
- إزالة الاعتماد الإجباري على الورديات/جلسات الصندوق من البيع.
- اعتماد الراتب الشهري الثابت بدل نظام الساعات، مع إبقاء الحقل القديم للتوافق فقط.
- حماية عمليات إدارة الموظفين وPIN ضمن الفرع الحالي.
- منع رقم الفاتورة الجديد من التصادم بين الفروع المستقلة.
- رفض استعادة ملف ليس قاعدة Nexora مشفّرة بمفتاح الجهاز.
- إنشاء نسخة أمان قبل الاستعادة وإغلاق اتصال SQLite قبل استبدال الملف.
- تسجيل تعديلات مخزون بطاقة المنتج في inventory_movements.
- الحفاظ على cost_at_sale عند تطبيق المبيعات المزامنة.
- إصلاح schema suppliers الذي كان يحتوي على تعريف id مكرر.

### التحقق
- 39 ملف JavaScript: syntax PASS.
- Security Regression: PASS.
- Payroll Regression: PASS.
- لا يمكن تشغيل اختبار SQLite native داخل بيئة العمل الحالية بدون تنزيل dependency `better-sqlite3-multiple-ciphers`; لم يتم اعتبار ذلك PASS.
