# Nexora POS — World Readiness / v0.8.0

هذه النسخة تستهدف **Global-Ready** على مستوى البرمجيات والبنية، وليس شهادة قانونية أو مصرفية أو ضريبية عالمية.

## ما أصبح أقوى في 0.8.0
- جلسات الصندوق اختيارية بالكامل؛ البيع لا يعتمد على وردية مفتوحة.
- رواتب شهرية مع تاريخ سريان واعتماد وصرف.
- رصيد متجر منفصل عن دين العميل.
- سجل العميل قابل للمزامنة بالأحداث.
- عزل الفروع وتصادم UUID محمي.
- تسجيل دخول أولي بدون كلمة مرور ثابتة مع rate limiting.
- GS1 1D/2D foundation.
- Backup/restore validation.

## الحدود الخارجية

PCI DSS، fiscalization، التوقيع القانوني، بوابات الدفع، شهادات الدولة، وأجهزة الطباعة/المسح تحتاج اعتماد البيئة والدولة والمزوّد الفعلي. لا تدّعي الحزمة بحد ذاتها هذه الشهادات.
