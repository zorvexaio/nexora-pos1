# Nexora POS v0.52.14

## Features
- Waiters can now request the bill for a table directly from their phone (🔔 button on the waiter app's table list). The main Tables screen highlights that table with a pulsing badge until a cashier/manager taps "تم" to acknowledge it. No payment or table closing happens from the waiter side — this only notifies staff.
- Tables screen now auto-refreshes every 8 seconds (paused while the tab isn't visible) so bill requests and occupancy show up without a manual refresh.
