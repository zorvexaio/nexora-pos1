# Nexora POS v0.36.0 — Premium UI

## What changed
- Premium visual design system across POS and management pages.
- Redesigned top navigation with stronger brand identity, active-state hierarchy, and responsive overflow behavior.
- Larger, more tactile product cards with better price emphasis and inventory visibility.
- Elevated search surface with stronger focus affordance.
- Upgraded cart, totals, payment method selectors, checkout CTA, modals, tables, report cards, and management tables.
- Refined dark theme and responsive layouts for smaller screens.
- Added reduced-motion support for accessibility and workstation comfort.
- No business logic or IPC contract changes in this release.

## Validation
- Added `tools/v0.36-regression.js` and included it in `npm run check`.
- Existing security, financial, payroll, sync, startup, and release-preflight suites remain required.
