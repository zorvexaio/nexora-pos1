# Nexora POS — Hardening Release v0.52.30

تاريخ: 2026-10-06

## الهدف
رفع جودة الإصدار من ~7.6/10 نحو أقصى ما يمكن إصلاحه من المصدر بدون بيئة ويندوز موقّعة أو اعتماد ضريبي حكومي.

## ما تم إصلاحه في هذا الإصدار

### 1) سلامة الإصدار (Integrity)
- إعادة توليد `CORE_SHA256.txt` و `CORE_SHA256_V0.52.30.txt` من الملفات الفعلية.
- مواءمة `VERSION` و `package.json` على `0.52.30`.
- حذف ملف الهاش القديم غير المطابق.

### 2) الوصولية (Accessibility)
- رابط تخطي (skip-link) في شاشة الدخول والكاشير.
- تبويبات الدخول بدور `tablist` / `aria-selected`.
- أخطاء الدخول وPIN بـ `role="alert"` و `aria-live`.
- لوحة PIN مع `aria-label` لكل مفتاح.
- `:focus-visible` واضح للوحة المفاتيح.
- دعم `prefers-contrast: more` و تعزيز `prefers-reduced-motion`.

### 3) سهولة الاستخدام
- زر إظهار/إخفاء كلمة المرور في شاشة الدخول.
- أهداف لمس بحد أدنى 44×44px للأزرار الحرجة (PIN، دخول، تنقل، إتمام بيع).
- اختصار **F4** لإتمام البيع، **F2** للبحث، **Escape** لمسح البحث.
- زر إتمام البيع أوضح (ارتفاع 52px + ظل).

### 4) Fiscalization
- توسيع واجهة `FiscalizationRegistry` (`setActive`, `list`, `status`).
- الإبقاء على Generic adapter صريحاً أنه **غير ممتثل** لأي دولة — لا ادعاء زائف.

### 5) ما لم يُغلق بعد (حدود خارجية)
هذه البنود **لا يمكن** إغلاقها من المصدر وحده:
1. توقيع Authenticode لمثبت ويندوز (يحتاج شهادة بائع).
2. اختبار طابعة/باركود حقيقي على جهاز ويندوز.
3. Adapter ضريبي رسمي (ZATCA / GIB / …) مع مفاتيح وبيئة اعتماد.
4. نشر قائمة إبطال تراخيص (`NEXORA_REVOCATION_LIST_URL`).
5. تشغيل كامل لـ `npm run check` على native Electron + SQLite مشفّر.

## أوامر التحقق بعد الاستخراج
```bash
npm ci
npm run rebuild
npm run check
# على ويندوز بعد البناء:
npm run dist:win:unsigned   # أو dist:win مع شهادة
```

هذا الإصدار يحسّن الجودة الفعلية للواجهة والأمن والسلامة، ولا يدّعي PCI DSS أو امتثال ضريبي حكومي أو توقيع كود غير موجود.
